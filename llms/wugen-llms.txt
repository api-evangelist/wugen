# Wugen / Allotera Therapeutics

> Wugen, Inc. is a St. Louis, Missouri clinical-stage cell-therapy company founded in 2018 out of
> Washington University in St. Louis, developing off-the-shelf allogeneic CAR-T and memory NK cell
> therapies for blood cancers. In July 2026 it renamed itself Allotera Therapeutics, Inc. and moved
> to alloteratx.com. Its lead program, soficabtagene geleucel (sofi-cel, formerly WU-CART-007), is a
> CD7-targeted allogeneic CAR-T with FDA Breakthrough Therapy designation, in a global pivotal study
> for relapsed or refractory T-ALL / T-LBL.

## What this company does and does not expose

Wugen/Allotera operates no developer program, no product API, no API portal, no SDK, no CLI, no
sandbox and no MCP server. It publishes no OpenAPI, no AsyncAPI, no agent card, no security.txt and
no api-catalog. This is normal for a clinical-stage biotech and is not a defect.

The one machine-readable surface either domain exposes is the WordPress REST API (wp/v2) behind the
corporate website. It is anonymously readable, and it is the only way to get this company's news,
publications and corporate content as structured data.

## APIs

- [Allotera Content API (WordPress REST wp/v2)](https://alloteratx.com/wp-json/wp/v2): Current
  corporate site. 81 posts (59 press releases, 12 scientific publications, 8 articles, 2 careers),
  18 pages, 66 media objects, 10 category terms, comments and site search. Anonymous, no credential.
- [Wugen Legacy Content API (WordPress REST wp/v2)](https://wugen.com/wp-json/wp/v2): The retired
  brand host. Its human site is now a single splash page forwarding to alloteratx.com, but the
  WordPress install still serves the full historical archive — 80 posts, 269 media objects, 11
  category terms — with no Sunset header and no API-layer redirect.

## Notes for agents

- Everything catalogued here is a GET. There is no write path a third party can reach.
- Paginate with page/per_page (per_page max 100) and stop at X-WP-TotalPages, or follow the
  rel="next" Link header. Paging past the end returns HTTP 400, not an empty array.
- Errors are `{code, message, data.status}` as application/json — this is not RFC 9457.
- No rate limits are published. Wordfence fronts both hosts and may throttle without warning.
- wugen.com returns HTTP 200 with its splash page for every path outside /wp-json/. Never treat a
  200 from that host as proof a document exists; diff the body against a control path.
- The therapeutic pipeline, trial arms and indications are NOT exposed as structured data. The `acf`
  custom-field block is empty on every object. That information exists only as rendered HTML.
